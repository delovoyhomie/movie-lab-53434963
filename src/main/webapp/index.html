Вход

Локальная демонстрация: student1 или student2, пароль student123.

Фильмы

Каждый атрибут — отдельная колонка. Таблица прокручивается по горизонтали. Пустые значения обозначены «—».

Справочники

Сначала можно создать местоположение, затем человека и координаты. При создании фильма выбираются существующие записи.

Специальные операции

Каждая операция выполняется функцией PostgreSQL через сервис приложения.

Порядок жанров: ACTION < WESTERN < COMEDY < FANTASY. Поиск слогана здесь учитывает регистр. Без наград = NULL. При переносе награды донора делятся поровну и прибавляются к наградам получателей; остаток — по ID.
